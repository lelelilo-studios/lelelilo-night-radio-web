# Night Radio

**A plush-pillow radio station at midnight: 18 rooms, each one a thing the ElevenLabs voice AI can do.**
Open it: **https://lelelilo-studios.github.io/lelelilo-night-radio-web/**

Every room plays the real sound the API made (voices, acted lines, a whole radio play, designed and remixed voices,
a changed voice, a cleaned-up voice, sound effects, music, transcripts, live captions, alignment, dubbing and a
voice agent), with an animation that follows it, and a care tag with exactly what went in, what came back, the call,
and what it cost.
